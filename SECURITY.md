# Security policy

## Reporting a vulnerability

Don't report security problems in public issues, discussions or pull requests.
Use the [security advisory form](https://github.com/unblocksyria/shaghal-extension/security/advisories/new)
and include:

- the affected version or commit;
- steps to reproduce, or a proof of concept;
- the expected and observed behavior;
- the impact.

Test only against accounts and data you control. Don't access or keep other
people's data, and don't send automated or high-volume traffic to the live
service.

We'll acknowledge your report as soon as we can and agree on a fix and disclosure
with you.

## Scope

This repository contains only the extension: its code, permissions, handling of
page addresses and screenshots, and use of the public Unblock Syria API. You can
report problems in the Unblock Syria website or API through the same form, and
we'll pass them on.

## Supported versions

Security fixes go to `main` and the latest
[Chrome Web Store](https://chromewebstore.google.com/detail/shaghal/epmjhaoobmgfclbkelhkiakijjocjgfm)
release.
